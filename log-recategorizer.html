Recategorizing changes the event's type (e.g. Break End → Clock In). Double-click a time value to edit it directly as text (format: YYYY-MM-DD HH:MM:SS), then press Enter or click away to stage the change — it turns bold until you hit Save. One Save button commits both the type and time change together. Changes take effect immediately and will reflow into your reports and dashboard.
Period Cutoff rows record where each reporting period ended; they don't count as time. Editing the time of the row marked Current cutoff also moves the live report cutoff on the time clock. Use Make current on an older cutoff row to roll the current period back to it, or Set cutoff in the Current period card to pick any date and time.
